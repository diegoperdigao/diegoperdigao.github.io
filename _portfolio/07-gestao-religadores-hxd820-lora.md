### Project Overview

Conducted under **Lei de TICs / MCTI**, this R&amp;D project created specialized operational control software for **HXD820** automatic single-phase distribution reclosers deployed along power feeder branches.

### Technical Scope &amp; Innovation

* **Dual LoRa &amp; Industrial Serial Stack:** Long-range radio telemetry paired with wired local field maintenance interfaces.
* **Remote Protection &amp; Telecontrol:** Safe remote switching, protection curve configuration, and state supervision.
* **Oscillography &amp; Grid Continuity:** Transient waveform capture supporting root-cause fault analysis and utility SAIDI/SAIFI (DEC/FEC) reduction.

### Visão Geral do Projeto

Projeto sob a **Lei de TICs / MCTI** voltado ao desenvolvimento de software especializado para supervisão operacional, parametrização e telecontrole de religadores monofásicos **HXD820** em ramais de distribuição elétrica.

### Escopo Técnico e Inovação

* **Pilha Dual LoRa e Serial:** Integração de rádio de longo alcance (LoRa) para operação remota com interface serial industrial para manutenção em campo.
* **Proteção e Telecontrole:** Manobras remotas seguras, ajustes de curvas de proteção e leitura de estado.
* **Oscilografia e Continuidade (DEC/FEC):** Registro oscilográfico de eventos transitórios para análise de faltas e melhoria contínua de indicadores de continuidade.
